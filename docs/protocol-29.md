## Android 行为

- **历史恢复。** 断线重连沿用相同 `historyId` 的内存历史，订阅同时发送最后一条事件的 sequence 和 `createdAt`。服务端返回 `reset: true` 时替换该会话的旧记录。服务端历史 ID 改变或缺失时，从头请求当前会话的历史窗口。继续处理直接快照、分块快照、确认和分页。
- **项目。** 登录快照与 `projects` 广播同步服务端项目。远程控制按设备 ID 和规范化路径归组，显示离线设备与空项目。在线且已就绪的电脑支持在项目中新建会话或移入空闲会话。项目菜单支持重命名及移除登记。
- **计划与审批。** `ExitPlanMode` 显示为 Markdown 计划，支持选择执行模式、改后执行和附意见退回。普通工具审批显示上游给出的理由与安全拦截提示，对话显示审批模式的切换记录。
- **额度与统计。** 账号页接收 `ready.quota` 和后续 `quota` 广播。会话设置读取 `session.stats`，显示估算费用，并从上一轮的运行用量中显示 1 小时和 5 分钟缓存写入。
- **帮助。** 侧栏帮助中心可搜索连接、项目、计划审批、用量及访问管理。

Android 通过 WSS 以 `tunnel=false` 连接。会话历史缓存在当前进程。桌面文件面板的 SFTP 通道、CLI 与 ACP、设备执行端由上游客户端提供。
